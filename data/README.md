# Данные

Сюда кладутся исходные выгрузки. Содержимое папки, кроме этого файла, в git
не попадает: исходные CSV большие и не должны коммититься.

| Файл | Что внутри | Строк |
|---|---|---|
| `df_Uid_data_hack.csv` | клиенты, разделитель `;` | 85 525 |
| `df_Uid_payment_hack.csv` | платежи: `BENEFICIARY`, `PAYER`, `PAY_AMT`, `PAY_CNT` | 1 380 585 |
| `df_Fid_Uid_link_hack.csv` | привязка офисов (`SYNTHETIC_F`) к клиентам | — |

Файлы только читаются. Из `df_Uid_data_hack.csv` и
`df_Uid_payment_hack.csv` собирается фикстура клиентов:

```bash
python -m scripts.build_clients_fixture
```

Скрипт повторяет правила DB-2/DB-3: выбрасывает все строки клиентов с
дублирующимся ID, превращает флаги продуктов в список, считает корзину
выручки, размер группы и число контрагентов.

Новости и первоисточники пока не собираются: для них нужны md-документы
банка (`app/fixtures/events.json`, `sources.json`).
